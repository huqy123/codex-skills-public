# Codex Public Skills

这里放可跨项目复用的 Codex skills，内容已经做过脱敏，适合用于代码调查、开发协作、发布检查和会话交接。

## 当前内容

- `plain-chinese`：用通俗、准确的中文写说明、注释和操作文档。
- `task-efficiency`：按任务风险选择调查、实现和验证范围，减少重复工作。
- `issue-code-trace`：追查一个代码或页面问题的触发路径、原因、提交时间线和当前状态。
- `release-candidate-review`：在提测、合并或发布前检查完整变更集和验证证据。
- `session-brief`：用户明确要求时整理会话交接内容，区分已完成和待验证事项。

## 使用方式

每个目录都有一个 `SKILL.md`。将需要的 skill 目录复制到 Codex 支持的 skills 目录后即可使用；具体安装方式以当前 Codex 客户端的说明为准。

## 脱敏范围

本仓库不包含公司项目代码、内部业务规则、客户资料、数据库脚本、接口地址、凭据或本机专用配置。
