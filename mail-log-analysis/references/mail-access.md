# 邮箱访问与状态保护

按当前可用连接和宿主工具文档选择方式。此参考不提供账号、服务器、脚本或默认授权，也不要求安装特定邮箱客户端。

## 已连接邮箱工具

- 核对工具当前账号、目标文件夹、时间范围、分页和标识语义。工具能搜索不代表已读取完整正文或附件。
- 优先不改变已读状态的读取入口。查询、读取、标记、移动、发送等能力分别对待，读取授权不包含其他操作。
- 只用工具返回的真实标识，不把标题或列表序号当作邮件唯一标识。

## 已登录浏览器

- 复用用户指定的浏览器和标签页，先核对账号与当前页面，不照抄旧选择器、页签ID或文件夹名称。
- 使用工具支持的页面读取方式。正文在框架中时，观察真实结构后读实际正文，不从隐藏应用状态或认证数据构造后台请求。
- 先确认打开邮件是否自动标读。若会改变状态，优先换用只读连接；只能网页读取时，先说明影响并取得对应状态处理授权。
- 授权保留原状态时记录每封原有标记，在工具支持范围内恢复并核验；不能仅靠总未读数相同证明同一批邮件的状态正确。
- 不点击全部标读，不关闭用户原有标签页，不为读取现有会话重复登录或猜验证码。无法恢复时明确报告，不说未产生变化。

## 已配置 IMAP 工作流

- 先检查真实工具、帮助及配置来源，只复用本次账号已授权的安全配置；不要读取或展示凭据文件。
- 支持时使用只读选择和 `BODY.PEEK[]`，避免读取正文时增加已读标记。首次确认服务器实际行为，不把命令名当成功证据。
- 邮件身份包含账号、服务器、文件夹、`UIDVALIDITY` 和 `UID`。文件夹标识变化后，旧UID不能直接用于当前邮件。
- 已授权标读时只为确切UID增加已读标记，保留其他标记，并查询验证。不把恢复任务当作默认可执行的写入步骤。
- 超时或响应未知先查当前标记再决定重试。身份或报告证据不匹配时停止该写操作，不修改旧完成记录绕过检查。

## 来源和恢复

正文摘要可帮助发现重复内容，但不等于服务器邮件身份。没有稳定标识时明确可追踪性限制，不编造UID或承诺精确补标。

按需记录批次、来源、报告位置、内容摘要和状态处理结果。报告保存失败、正文不完整、已分析但标记失败是不同状态；分别恢复，不以重读全部或全部标读代替。

不对未读取或未解析的附件写“已完整分析”。缺片、权限不足和连接失败属于处理限制，不直接当作应用Bug。
